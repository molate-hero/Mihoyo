# Shell / Kernel Demo

Godot 4.7.2，GDScript，Compatibility 渲染。魔方外壳使用 `lands.blend` 的六面建筑模型；角色使用在 Blender 中整理、改色的 Kenney 骨骼人物；内核房间仍是白模。

## 运行

在 Godot 中导入 `project.godot`，按 F5 运行，或执行：

```bash
godot --path .
```

默认进入局域网房间界面。运行使用已导出的 GLB，无需 Blender 插件或 MCP。

## 局域网双人

1. 两台电脑使用同一份项目和 Godot 4.7.2，连接同一路由器或可互相访问的局域网。
2. 创建者选择 Kate 或 Sarah，点击“创建房间”。记下界面显示的实际网卡 IPv4 地址；默认端口24567。
3. 另一台电脑输入主机 IP、使用相同端口，点击“加入房间”，自动分配另一角色。
4. 双方点击“准备”，全部准备后开始。
5. 两台电脑都显示等尺寸双人分屏，但只允许操作自己角色。Kate 使用 WASD 或方向键、选择轴/层和 Q/E；Sarah 使用 WASD 和空格。双方都可在自己的视口按住鼠标左键拖动旋转视角，松开左键或 Esc 停止转动。
6. 只有主机可使用 R 重置。点击“离开房间”可退出；断线立即停止游戏并返回房间界面，重新加入、准备后从起点开始。

无需互联网或额外服务器。若连接失败，确认主机 IP 属于实际连接的网卡、端口一致，并允许主机防火墙的入站 UDP 24567（如修改端口，则允许对应端口）。部分访客 Wi-Fi 开启设备隔离，需要切换到能互相访问的网络。不要给远端玩家填写127.0.0.1；它只适用于同机测试。

双方脚本和模型会进行一致性检查，不同版本不能开始游戏。没有自动发现、房间码或断线续玩功能。

本机测试可开两个独立进程：

```bash
godot --path . -- --host --role=kate
godot --path . -- --join=127.0.0.1
```

可加 `--port=24568` 修改端口。开发用原同机模式：`godot --path . -- --offline`。

### 同步方式

主机统一模拟两名角色，判定道路、转动、深井和胜负；客户端仅预测自己角色的移动并发送带编号的输入，房主仍负责最终判定。移动输入30Hz、世界快照20Hz，远端角色插值显示，本地角色即时预测。快照压缩后传输，转动/进入井口/重置指令可靠发送；角色权限在主机校验。房主只执行已收到的移动输入；没有新输入时停止，不会在断包后持续行走。

Sarah 的外壳位置仍以面片 ID 和面内坐标保存，跨面片时换算镜头参考系。镜头控制在本地处理，另一台电脑可看到同步的 Kate 和 Sarah 视角。加入方按固定30Hz预测本地移动，收到房主确认后回放尚未确认的输入；丢包时重复发送未确认输入，房主按编号去重。同一角色的速度不因房主/加入方身份或渲染帧率改变。断网后预测最多保留约2秒输入，避免无限偏离房主状态。

## 操作

左右视口等宽等高，双方均为第三人称跟随镜头。联机时每台电脑只控制自己的角色；`--offline` 才使用同一键盘控制两人。

| 角色 | 操作 |
| --- | --- |
| Kate | WASD/方向键在内核房间移动，靠近桌子才能转动魔方 |
| Kate | 1/2/3 选择 X/Y/Z 轴，7/8/9 选择负侧/中间/正侧层 |
| Kate | Q/E 转动 -90°/+90°，也可点击按钮 |
| Kate | 在左侧画面按住左键拖动旋转镜头，松开左键或 Esc 停止转动 |
| Sarah | WASD 相对镜头沿道路移动，角色转向实际行进方向 |
| Sarah | 在右侧画面按住左键拖动旋转镜头，松开左键或 Esc 停止转动 |
| Sarah | 在青绿色 X 井口中央按空格进入内核 |
| 主机 | R 重置固定谜题 |

首次体验：默认已选择 X 轴正侧层（层2），Kate 按 E 撤销初始打乱。Sarah 从沙漠的 Node 0 出发，先按 W 向前走，再沿灰色道路经过绿洲、胡同、园林、山地，最后到达欧洲城市的 Node X。路线跨越全部六面；路口转弯时可用左键调整镜头，再按 W 前行。进入内核后镜头重置，Sarah 按 A 走近蓝色 Kate 即通关。

## 模型接入

- 原始 `lands.blend` 保持不变。
- `assets/lands.glb` 按三阶魔方分成26个可独立转动的块体；跨格子的地面、道路和建筑按面片边界切分。
- Blender 的边长9统一缩放为 Demo 的边长6，并转换为 Godot 的 Y 向上坐标。
- `assets/lands_navigation.json` 从原模型道路网格提取136个道路矩形，包含54个面片、道路开口、起点、终点及原始路线。
- 实际通行判定使用这些道路，而不是原先的十字/直线白模道路。开口位置与宽度对齐后可跨格或跨魔方棱边。
- 外壳与桌上魔方使用同一模型，同步转动。原模型的灯光、相机和整体控制器不导入。
- 派生模型将 Node X 处的装饰喷泉替换为游戏井口，原始 Blender 文件中的喷泉仍保留。

修改 Blender 模型后重新生成：

```bash
blender --background lands.blend --python tools/export_lands.py
godot --headless --path . --editor --import --quit
```

项目关闭 Godot 直接导入 `.blend`，避免重复导入整颗模型和依赖编辑器的 Blender 路径设置。

## 临时规则与限制

- 初始状态是固定、可解的一次打乱，不要求还原魔方；可自由实验其他转动。
- 每次只转一层、90°、持续0.65秒；动画期间拒绝新转动。内核保持固定。
- Sarah 随所属面片转动，站立与镜头参考系跟随面片法线。
- 接缝附近不能发起转动，转动时禁止跨面片。跨棱边按新的面法线切换重力参考系。
- 移动使用道路约束，没有跳跃、坠落、刚体重力或建筑碰撞；建筑目前是视觉资产，镜头也尚无建筑避障。
- Kate 和 Sarah 的镜头都跟随各自的位置，但不会因角色行进方向而自动转向。水平与俯仰由左键拖动控制；WASD 实时相对当前镜头方向移动。Sarah 跨魔方棱边时仍转换重力参考系，保持相对面片的镜头方向。
- Sarah 尺寸为0.2倍，外壳速度0.3、内核速度0.4单位/秒，镜头和交互范围使用同一缩放参数。
- Kate 可用鼠标环绕视角，在桌边使用按钮/按键控制魔方，尚未实现直接抓取。
- 深井使用淡入淡出过渡，没有真实井道。进入后关闭转动控制，0.52单位距离内判定汇合。
- 支持两人局域网直连；暂不支持公网中继、手柄、保存、撤销或随机关卡。

## 验证

```bash
godot --headless --path . -- --self-test
```

检查等尺寸分屏、第三人称跟随、26块体/54面片、九种层转动四次复原、初始断路与解法、开口双向连接、完整六面道路与实际移动、跨面路线从0到X、转动期间角色跟随、进入内核、通关、重置、鼠标镜头与相对移动。失败以非零退出码结束。

局域网回归检查：

```bash
python tools/test_lan.py
```

启动两个独立 ENet 进程，分别测试主机扮演 Kate / Sarah，验证角色权限、真实移动与转动同步、深井、通关、重置、断线、版本不一致与连接超时。深井和通关测试使用主机测试夹具定位角色；六面实际行走由 `--self-test` 完整验证。已验证同机回环连接，跨两台实体电脑的网络和防火墙需现场确认。

截图：`godot --path . -- --capture` 输出游戏预览；`--capture-lobby` 输出 `lan-preview.png`。

## 人物模型

人物基于 Kenney Mini Characters（CC0）的 female-e / female-b，分别用于 Kate / Sarah。在 Blender 中调整配色、原点、朝向与身高，并保留待机和行走骨骼动画。Kate 基准身高1.4，Sarah 基准身高0.76，Sarah 仍应用 `SARAH_SCALE = 0.2`；相机、速度与通行范围保持此前设定。

- 可编辑源文件：`assets/characters/kate.blend`、`assets/characters/sarah.blend`。
- 游戏资产：对应的 `.glb`，已嵌入贴图，带 `idle` / `walk` 动画。
- 角色实际移动时播放 walk，停下或受道路阻挡时播放 idle；Kate 的外观会随移动方向转身。
- 生成脚本：`blender --background --python tools/build_characters.py`，随后重新导入 Godot。
- 来源、改动及授权记录见 `assets/characters/CREDITS.md` 和 `source/License.txt`。

左键拖动采用普通可见鼠标，不会将指针移到屏幕中央；拖到窗口边缘后，可松开并重新拖动继续旋转。
